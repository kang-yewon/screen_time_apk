# 벽돌 타이머 (screen_time_apk)

설정한 시간 동안 핸드폰을 시계 확인과 전화 통화만 가능한 **벽돌 모드**로 잠그는 안드로이드 스크린타임 조절 앱입니다.

## 주요 기능
1. **잠금 시간 입력 및 프리셋**: 시간/분 직접 입력 또는 15분, 30분, 1시간, 2시간 빠른 선택
2. **2단계 경고 팝업**: 실행 버튼 클릭 시 `"경고: 진짜 하시겠습니까?"` 확인 팝업 표시 후 최종 `[실행]` 클릭 시 즉시 잠금 시작
3. **즉시 무음 전환**: 잠금 즉시 벨소리/알림음을 무음 및 방해금지(DND) 모드로 강제 유지 (잠금 종료 시 원래 상태로 자동 복구)
4. **알림 완벽 차단**: 잠금 시간 동안 전화 관련 알림을 제외한 모든 앱 알림 즉시 삭제
5. **앱 실행 차단**: 전화(다이얼러/통화 화면)를 제외한 다른 모든 앱 진입 시 즉시 검은색 시계 잠금화면으로 강제 복귀
6. **시계 & 전화 전용 잠금화면**: 현재 시각, 날짜, 남은 잠금 시간 카운트다운 표시 및 `전화 걸기` 버튼 제공
